# BareFilter (beta)

A short list of fixes for pages that push you to an app. uBlock Origin reads it and keeps it up to date, so a fix can reach you without a new Bare.

It is on by default. Switch it off in Extensions.

Today it covers the app prompts on Reddit, m.facebook.com and m.youtube.com.

The list is [`BareFilter.txt`](BareFilter.txt), plain uBlock rules. Bare fetches that file and nothing else for this. If a rule breaks a page, open an issue with the address.
