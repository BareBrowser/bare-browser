# BareFilter (beta)

A short list of fixes for pages that push you to an app. It runs inside uBlock Origin, which Bare already ships.

It is on by default. Switch it off in Extensions. The rules show up under uBlock Origin's My filters, between the lines `! BareFilter begin` and `! BareFilter end`. Anything else you wrote there is left alone.

Today it covers the app prompts on Reddit, m.facebook.com and m.youtube.com.

The rules are built into Bare, so a fix needs a new Bare. [`BareFilter.txt`](BareFilter.txt) is the same list. The plan is for Bare to fetch that file from here instead, so fixes can arrive on their own. That is not done yet and nothing is fetched today.
